## 2023-10-27 - Added timeouts to external API calls\n**Vulnerability:** External fetch requests to webhooks and custom URLs had no timeout configured.\n**Learning:** In Node.js environment, fetch without timeout could hang indefinitely and lead to socket/memory leaks, posing a Denial of Service (DoS) risk if external services are unavailable.\n**Prevention:** Always include `signal: AbortSignal.timeout(ms)` for all `fetch` calls involving external un-trusted endpoints.

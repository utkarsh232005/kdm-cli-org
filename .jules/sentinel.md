## 2024-05-18 - Path Traversal Vulnerability in FileCacheProvider
**Vulnerability:** A Path Traversal vulnerability was present in the `FileCacheProvider` (`src/cache/file-cache.ts`) which constructs file paths using `path.join(this.cacheDir, key)`. If an attacker can control the cache key, they could inject `../` to access or overwrite arbitrary files on the local filesystem.
**Learning:** This vulnerability existed because the cache key was passed directly to the path constructor without any validation to ensure the resolved file path was physically located inside the intended cache directory. Even with a default cache directory, failure to strictly contain paths creates a severe risk.
**Prevention:** To avoid this next time, always securely resolve paths when using user-influenced inputs or variables to construct file paths. Use `path.normalize()` and explicitly check that the resolved absolute path `.startsWith(safeBaseDir + path.sep)` before proceeding with any file operation.
